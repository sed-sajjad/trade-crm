نسخهٔ نصب‌شدهٔ محلی `1.2.0`، نسخهٔ فهرست `2` و نسخهٔ schema همان `1.1.0` است. پشتیبان SQL کامل و گزارش مقایسهٔ قبل/بعد در پوشهٔ خصوصی خارج از web root ذخیره شدند و داخل بستهٔ افزونه قرار ندارند. متن راهنمای بالای فرم با الزامی‌بودن حوزه هماهنگ شد.

پس از پایان آزمون‌ها، دیتابیس موقت حذف و سرور مرورگر متوقف شد. برای تکرار آزمون، یک دیتابیس خالی جدید با پیشوند اعلام‌شده بسازید. تصویرهای تست فقط شامل مخاطبان ساختگی‌اند و داخل بستهٔ نصب قرار ندارند.

آزمون مرورگر، build واقعی و لایه‌های REST/اعتبارسنجی/دیتابیس را در دیتابیس جدا استفاده کرد؛ فقط احراز هویت در آداپتور محلیِ محدود به توکن جایگزین شد و Service Worker مرورگر در این تست خاموش بود. آزمون با REST استاندارد `/wp-json/` اجرا شد. در بازبینی یک محدودیت قبلی دیده شد: ساخت URL در frontend برای حالت پیوند یکتای ساده با `?rest_route=` درست نیست؛ این مسیر در تغییر فهرست اصلاح یا موفق اعلام نشده است. برای اجرای فعلی از پیوند یکتای غیرساده استفاده شود.

آزمون بار ۱۰۰ هزار مخاطب، نصب روی دستگاه واقعی iPhone/Android و انتشار روی سایت آنلاین در این بررسی اجرا نشده‌اند. نتایج نسخه‌های قبلی زیر برای سابقه حفظ شده‌اند و به‌معنای اجرای مجدد آن‌ها در نسخهٔ ۱٫۲٫۰ نیستند.

## گزارش قبلی نسخه ۱٫۱٫۳

بررسی جدید در ۱۴ اکتبر ۲۰۲۶ به وقت تهران با PHP 8.1.10 انجام شد. گزارش نسخه قبلی پایین‌تر حفظ شده است.

| آزمون نسخه ۱٫۱٫۳ | نتیجه |
|---|---|
| آزمون HTTP با افزونه روشن/خاموش روی WordPress 7.1.3 محلی | ۵۰ بررسی موفق؛ مسیر ریشه و نصب در زیرپوشه، صفحات عمومی، ورود، sitemap، robots، query string، دسترسی مهمان/کاربر فاقد مجوز/مدیر، هدرهای کش و noindex و محدوده PWA |
| آزمون HTTP روی کپی محلی magicamoghaddam | ۲۰ بررسی موفق با Elementor، Elementor Pro، Rank Math، WPML و Gravity Forms فعال؛ مقایسه عنوان، H1، meta، canonical، hreflang، JSON-LD، CSS/JS و رفتار مسیرهای عمومی با حالت بدون CRM |
| چرخه فعال‌سازی/غیرفعال‌سازی و تداخل مسیر | ۲۴ بررسی موفق؛ توقف فعال‌سازی در تداخل با برگه/نوشته/مسیر افزونه دیگر، حفظ داده‌ها و روابط CRM، حفظ تنظیمات سایت، حذف فقط قوانین خود افزونه و ثابت‌ماندن هش `.htaccess` |
| آزمون REST فقط‌خواندنی WordPress | موفق؛ مهمان ۴۰۱، مدیر ۲۰۰، ۲۴۵ ناحیه تلفن، جست‌وجوی حوزه و no-store؛ شمار مخاطبان موجود همچنان ۱ |
| `tests/run.php` | ۵ بررسی موفق نرمال‌سازی و شماره تلفن |
| `pnpm test` | ۵ آزمون تقویم موفق |
| PHP lint | فایل‌های PHP افزونه و آزمون‌ها بدون خطای نحوی |
| `pnpm build` | TypeScript و Vite موفق؛ فایل‌های برنامه ساخته شدند |

یک رگرسیون روی صفحه نخست ثابت در کپی سایت کشف و رفع شد: ثبت متغیرهای عمومی `trade_crm_*` همراه با query string می‌توانست WordPress را به نمایش صفحه وبلاگ و Rank Math را به تولید canonical وبلاگ وادار کند. متغیرهای عمومی حذف شدند و مسیریابی فقط آدرس دقیق endpointها را بررسی می‌کند. تست فعال/غیرفعال روی همین کپی، اصلاح را تأیید کرد.

ابزار HTTP با PHP built-in server روی 127.0.0.1، توکن موقت و فیلترهای درون همان درخواست اجرا شد. ابزار آزمون در بسته قابل نصب قرار ندارد. Service Worker تولیدشده در محیط JavaScript آزمایش شد: فقط کش نسخه‌های همین نصب حذف می‌شود و درخواست صفحات عمومی، ورود، پیشخوان و REST رهگیری نمی‌شود. این آزمون، نصب واقعی PWA روی موبایل نیست.

آزمون چرخه نصب فقط روی WordPress آزمایشی trade-crm اجرا شد؛ برگه و نوشته موقت در پایان پاک و گزینه‌های موقت بازگردانده شدند. کپی محلی سایت مقصد با نسخه فعلی آنلاین یکسان نیست: WordPress 7.0 و Elementor 4.1.4 در کپی، در برابر نسخه‌های اعلام‌شده 7.1.3 و 4.2.4 در HTML آنلاین. هیچ نصب یا تغییری روی سایت آنلاین انجام نشد. آزمون تعاملی ویرایشگر، ارسال فرم، بار واقعی و کش LiteSpeed/CDN آنلاین انجام نشده است؛ مراحل لازم در `DEPLOYMENT-magicamoghaddam.fa.md` ثبت شده‌اند.

اجرای مجدد از سورس، فقط روی محیط محلی:

```powershell
$env:TRADE_CRM_WP_ROOT = 'C:\laragon\www\trade-crm'
$env:PHP_BINARY = 'C:\laragon\bin\php\php-8.1.10-Win32-vs16-x64\php.exe'
node tests/site-isolation.mjs
$env:TRADE_CRM_ALLOW_LOCAL_FIXTURES = '1'
& $env:PHP_BINARY tests/wordpress-site-isolation.php
& $env:PHP_BINARY tests/wordpress-smoke.php
```

دیتابیس محلی از قبل یک مخاطب و دو حوزه سفارشی در سطح اصلی داشت. آزمون migration ارتباط‌های مخاطب با حوزه‌ها را بدون تغییر تأیید کرد. آزمون یکپارچه یک مخاطب موقت با شماره ساختگی ساخت و در پایان مخاطب، شماره، سابقه و ارتباط حوزه‌اش را پاک کرد؛ شمار مخاطبان پس از آزمون همچنان یک بود و دسته آزمایشی باقی نماند. دسته‌های سفارشی قدیمی حذف نشدند و در نتیجه شمار کل ریشه‌های این نصب ۲۷ است.

این موارد در این محیط اجرا نشده‌اند: آزمون رابط با Playwright و نقش سرپرست جدا از مدیر، آزمون بار ۱۰۰ هزار مخاطب و پنج کاربر هم‌زمان، و نصب روی دستگاه واقعی iPhone یا Android. اجرای برنامه روی گوشی واقعی همچنین به دامنه HTTPS نیاز دارد. این موارد به‌عنوان موفق گزارش نمی‌شوند.
