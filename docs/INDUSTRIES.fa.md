# فهرست حوزه‌های فعالیت CRM بازرگان

افزونهٔ ۱٫۲٫۰ — فهرست نسخهٔ ۲؛ ۲۵ دستهٔ اصلی، ۵۴۷ مورد شامل ۲۹۰ افزودهٔ جدید، حداکثر سه سطح.

این شمار مربوط به نصب تازه است. حوزه‌های سفارشی و تغییرات قبلی شما هنگام ارتقا حفظ می‌شوند؛ ازاین‌رو شمار نصب موجود می‌تواند متفاوت باشد. انتخاب هر سطح و چند حوزه برای مخاطب ممکن است. برای یافتن تأمین‌کنندهٔ کیوی، «کیوی» را جست‌وجو کنید.
